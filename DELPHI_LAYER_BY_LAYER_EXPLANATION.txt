1. ARCHITECTURAL CORE PRINCIPLES
================================================================================
DELPHI was engineered under strict foundational constraints codified in AGENTS.md:
1. No External LLM APIs: System must never depend on third-party commercial APIs.
2. No Pretrained Weights: Every weight matrix is trained from scratch on domain data.
3. Strict Temporal Integrity: No feature, embedding, model checkpoint, or citation
   dated after a forecast cutoff timestamp (T_forecast) can be accessed.
4. Deterministic Intelligence: Prefer deterministic mathematics, structured graphs,
   and calibrated small neural models over ungrounded generative hallucinations.
5. Modularity: 14 distinct layers (Layer 0 to Layer 13) communicating via strict,
   typed data schemas.

--------------------------------------------------------------------------------
LAYER 0: SYSTEM FOUNDATION, CONTRACTS & SCHEMAS
--------------------------------------------------------------------------------
- Purpose: Establishes base directories, strict type contracts, configuration
  parsers, and validation schemas used across all downstream modules.
- Implementation Files:
  * config/config.yaml, config/model_config.yaml, config/training_config.yaml
  * src/delphi/datasets/schemas.py
- Primary Schemas:
  * NewsArticle: text, title, source_domain, published_at, url, metadata
  * StructuredEvent: event_id, actor1, actor2, event_code, timestamp, geo
  * Scenario: scenario_id, title, probability, timeline, indicators
- How It Works:
  All components communicate exclusively through immutable dataclasses and
  Pydantic V2 schemas. No loose dictionaries are passed between layers.

--------------------------------------------------------------------------------
LAYER 1: DATA INGESTION & TEMPORAL SPLITTING
--------------------------------------------------------------------------------
- Purpose: Ingests unstructured and semi-structured global feeds (GDELT V2,
  ICEWS, UN Comtrade, RSS) and enforces chronological training splits.
- Implementation Files:
  * src/delphi/ingestion/ (adapters for GDELT, ICEWS, Web)
  * src/delphi/preprocessing/temporal.py
  * src/delphi/preprocessing/deduplication.py
- How It Works:
  1. Ingestion: Parses raw CSV, JSONL, and XML into unified NewsArticle objects.
  2. Deduplication: Removes exact and near-duplicate articles using MinHash
     fingerprinting to eliminate syndication duplicates.
  3. Temporal Partitions: Partitions data strictly along time boundaries:
     * Train: Up to T_train_end (e.g., 2022-12-31)
     * Validation: T_train_end to T_val_end (e.g., 2023-12-31)
     * Test: T_val_end to present (e.g., 2024-01-01 onward)
  Crucially, no record from a later time split can ever exist in an earlier split.

--------------------------------------------------------------------------------
LAYER 2: DETERMINISTIC CUSTOM TOKENIZER
--------------------------------------------------------------------------------
- Purpose: Converts raw natural language text into integer sequences of token IDs
  and character matrices without relying on external tokenizer libraries.
- Implementation Files:
  * src/delphi/tokenizer/tokenizer.py
  * src/delphi/tokenizer/vocabulary.py
  * src/delphi/tokenizer/normalization.py
  * src/delphi/tokenizer/pretokenizer.py
  * src/delphi/tokenizer/special_tokens.py
  * models/vocab/vocabulary.json
- Mechanics:
  1. Normalization: Applies Unicode NFKC normalization, strips control chars,
     normalizes quotes and spaces.
  2. Pretokenization: Regex pattern split on whitespace, punctuation, and numeric
     boundaries while preserving geopolitical acronyms (e.g., "NATO", "UN", "US").
  3. Special Tokens: Fixed reserved indices:
     * <PAD> = 0, <UNK> = 1, <BOS> = 2, <EOS> = 3, <EVENT> = 4, <ACTOR> = 5
  4. Dual Output:
     * Token IDs: 1D tensor [Batch, Sequence_Length]
     * Character IDs: 2D tensor [Batch, Sequence_Length, Max_Word_Length]
- Result: 100% deterministic encoding. Same text always yields exact same tokens.

--------------------------------------------------------------------------------
LAYER 3: EVENTEMBED (WORD2VEC + CHAR-CNN)
--------------------------------------------------------------------------------
- Purpose: Transforms token IDs and character matrices into continuous, dense
  256-dimensional semantic event vectors.
- Total Parameters: 281,120 (~0.28M)
- Implementation Files:
  * src/delphi/models/eventembed/model.py
  * src/delphi/models/eventembed/char_cnn.py
  * models/eventembed/model.pt
- Architecture:
  1. Word Branch (192,000 params):
     * Embedding Matrix: [Vocabulary_Size (1000) x 192 dim]
  2. Character Branch (22,656 params):
     * Char Embedding: [128 ASCII chars x 32 dim]
     * Parallel Conv1D Banks:
       - Kernel size 3: 32 filters -> captures prefixes/roots (3,072 params)
       - Kernel size 4: 32 filters -> captures stems (4,096 params)
       - Kernel size 5: 32 filters -> captures suffixes/compounds (5,120 params)
     * Max-Over-Time Pooling: Extracts the strongest feature per filter bank (96 dim).
     * Linear Projection: 96 dim -> 64 dim (6,144 params).
  3. Fusion MLP (66,464 params):
     * Concatenates Word (192d) + Char (64d) = 256 dimensions.
     * LayerNorm + Linear(256 -> 256) + GELU + Linear(256 -> 256).
- Why Char-CNN?
  Standard embeddings break on unseen geopolitical names or misspelled actors
  (e.g., "Zelenskyy" vs "Zelensky"). The Char-CNN preserves semantic proximity
  by examining the subword character sequence directly.

--------------------------------------------------------------------------------
LAYER 4: EVENTNET (BILSTM + MULTI-HEAD SELF-ATTENTION EXTRACTOR)
--------------------------------------------------------------------------------
- Purpose: Ingests 256-dim token vectors and extracts structured event records:
  Who did What to Whom, When, and Where (CAMEO standard taxonomy).
- Total Parameters: 724,995 (~0.72M)
- Implementation Files:
  * src/delphi/models/eventnet/model.py
  * src/delphi/models/eventnet/attention.py
  * models/eventnet/model.pt
- Architecture:
  1. Sequence Encoder (395,264 params):
     * Bidirectional LSTM: 1 layer, 256 input dim, 128 hidden dim per direction.
     * Forward + Backward concatenation yields 256-dim contextualized states.
  2. Multi-Head Self-Attention (263,168 params):
     * 4 Attention Heads, Query/Key/Value projections [256 x 256].
     * Allows every token to attend to distant tokens in the paragraph.
  3. Multi-Task Output Heads (66,563 params):
     * Token-Level Entity Head (2,313 params):
       IOB tagger classifying each token as Actor, Target, Date, or Location.
     * Sequence-Level Event Head (64,250 params):
       Linear projection to 250 CAMEO event categories (e.g., 010=Make Statement,
       020=Appeal, 070=Provide Aid, 140=Protest, 170=Military Assault).
- Output: StructuredEvent object with normalized actor codes and event classes.

--------------------------------------------------------------------------------
LAYER 5: HISTORICAL INTELLIGENCE & FAISS VECTOR STORE
--------------------------------------------------------------------------------
- Purpose: Ground future forecasts in verifiable historical precedents. Finds
  situations in world history that match current crisis dynamics.
- Implementation Files:
  * src/delphi/retrieval/faiss_index.py
  * src/delphi/retrieval/historical_matcher.py
  * src/delphi/retrieval/reranker.py
  * indexes/historical/index.faiss (10.2 MB)
  * indexes/historical/metadata.parquet (47.7 MB)
- Mechanics:
  1. Offline Indexing: 10,000+ historical crises and events (1990–2024) encoded
     via EventEmbed into 256-dimensional vectors. Vectors are L2 normalized.
  2. Nearest Neighbor Search: Uses FAISS (IndexFlatIP / Cosine Similarity)
     to retrieve top-K candidates in < 2 milliseconds.
  3. Strict Temporal Filtering: Any vector whose timestamp >= T_forecast is
     masked out dynamically using Parquet metadata filtering.
  4. Multi-Factor Reranker: Reranks candidates based on:
     Score = 0.55 * Cosine_Similarity + 0.25 * Actor_Overlap + 0.20 * Domain_Match
- Output: Ranked historical analogues with known resolution timelines.

--------------------------------------------------------------------------------
LAYER 6: CREDNET (SOURCE CREDIBILITY SCORER)
--------------------------------------------------------------------------------
- Purpose: Evaluates the credibility and bias of source articles to prevent
  disinformation from corrupting scenario weights.
- Total Parameters: 961 (<0.001M)
- Implementation Files:
  * src/delphi/models/crednet/model.py
  * models/crednet/model.pt
- Architecture:
  * Input: 12 engineered features:
    1. Domain registration age (days)
    2. Author presence (binary)
    3. Citation density (links/tokens)
    4. Headline sentiment extremity (absolute polarity)
    5. Historic retraction count
    6. Quotes per paragraph
    7. Punctuation sensationalism ratio
    8. Publisher fact-check rating
    9. Readability grade level
    10. Anonymous source ratio
    11. Text length normality
    12. Publication consistency score
  * Layer 1: Linear(12 -> 32) + BatchNorm + ReLU (416 params)
  * Layer 2: Linear(32 -> 16) + ReLU (528 params)
  * Output: Linear(16 -> 1) + Sigmoid (17 params)
- Output: Scalar Credibility Score C in [0.0, 1.0]. Articles with C < 0.35 are
  downweighted or flagged during scenario synthesis.

--------------------------------------------------------------------------------
LAYER 7: CAUSALSEQ (SEQ2SEQ TRAJECTORY PROJECTION ENGINE)
--------------------------------------------------------------------------------
- Purpose: Models multi-step event chains and projects causal future sequences.
  Given past events E(t-k)...E(t), generates likely future events E(t+1)...E(t+n).
- Total Parameters: 2,928,649 (~2.93M)
- Implementation Files:
  * src/delphi/models/causalseq/model.py
  * src/delphi/models/causalseq/encoder.py
  * src/delphi/models/causalseq/decoder.py
  * src/delphi/models/causalseq/attention.py
  * models/causalseq/model.pt
- Architecture:
  1. Trajectory Encoder (1,315,328 params):
     * Bidirectional LSTM (256 hidden units per direction = 512 dim).
     * Linear projections map bidirectional states to initial decoder states.
  2. Bahdanau Additive Attention (197,377 params):
     * Energy = v_a^T * tanh(W_a * s_{t-1} + U_a * h_i)
     * Directs attention to the specific historical event triggering escalation.
  3. Autoregressive Decoder LSTM (1,050,624 params):
     * Ingests previous step prediction + attention context vector (768 total dim).
     * Generates hidden state s_t.
  4. Multi-Branch Projection Heads (365,320 params):
     * Event Type Head: Linear(256 -> 253) -> Next event CAMEO code.
     * Time Delta Head: Linear(256 -> 15) -> Days until next event (1 to 90 days).
     * Source Actor Head: Linear(256 -> 500) -> Who initiates next event.
     * Target Actor Head: Linear(256 -> 500) -> Who receives next event.
     * Domain Head: Linear(256 -> 20) -> Sector (Military, Diplomatic, Trade).
- Output: Tree of projected future causal trajectories with probability branches.

--------------------------------------------------------------------------------
LAYER 8: FORECAST ORCHESTRATION & SCENARIO SYNTHESIS
--------------------------------------------------------------------------------
- Purpose: Integrates extractions from EventNet, historical analogues from FAISS,
  credibility scores from CredNet, and rollouts from CausalSeq into 3–5 distinct
  narrative scenarios.
- Implementation Files:
  * src/delphi/forecast/orchestrator.py
  * src/delphi/forecast/scenario_builder.py
  * src/delphi/forecast/scenario_scorer.py
  * src/delphi/forecast/indicators.py
- Synthesis Algorithm:
  1. Trajectory Clustering: Runs 50 stochastic CausalSeq rollout paths; clusters
     them via DBSCAN over trajectory embedding space into discrete clusters.
  2. Scenario Synthesis:
     * Base Case (Most probable trajectory)
     * Escalation Case (High-volatility trajectory)
     * De-escalation / Diplomatic Resolution
  3. Probability Scoring: Computes raw cluster weight based on:
     * CausalSeq sequence log-likelihood
     * Historical analogue support frequency
     * Ingested news source credibility scores
  4. What-to-Watch Indicators: Automatically derives tripwire events:
     e.g., "Watch for troop movement across border X within 14 days".

--------------------------------------------------------------------------------
LAYER 9: TEMPORAL DATA LEAKAGE GUARD & CALIBRATION
--------------------------------------------------------------------------------
- Purpose: Enforces scientific evaluation rigor, ensures backtest validity, and
  calibrates raw model confidence scores into genuine empirical probabilities.
- Implementation Files:
  * src/delphi/forecast/validation.py
  * src/delphi/forecast/calibration.py
  * models/calibration/calibration.json
- Mechanics:
  1. Strict Temporal Leakage Guard:
     * When a forecast is requested with Cutoff Date T_cutoff:
       - Every article published after T_cutoff is purged.
       - Model checkpoints trained on data past T_cutoff trigger a 400 error.
       - Vector index queries discard all records with timestamp > T_cutoff.
     * Hard ValueError / 400 Bad Request if temporal violation is attempted.
  2. Temperature Scaling & Calibration:
     * Raw neural network logits are notoriously overconfident.
     * Layer 9 applies Platt Temperature Scaling:
       P_calibrated(y_i) = softmax(z_i / T)
     * Fitted Temperature T = 1.3612 reduces Expected Calibration Error (ECE)
       from 0.24 down to 0.099.

LAYER 12: AUTOMATED WALK-FORWARD BACKTESTING
--------------------------------------------------------------------------------
- Purpose: Continuously evaluates DELPHI's forecasting accuracy on historical
  data by stepping through time in sliding windows.
- Implementation Files:
  * scripts/temporal_backtest.py
  * src/delphi/api/routes/backtests.py
- Methodology:
  1. Selects an anchor date in the past (e.g., 2023-06-01).
  2. Freezes knowledge to that exact date.
  3. Forecasts events 30, 60, and 90 days into the future.
  4. Compares forecast against actual historical events recorded after that date.
  5. Computes Brier Score, Top-K Accuracy, and Precision@K.

5. CONCRETE END-TO-END WALKTHROUGH EXAMPLE
================================================================================
Input: User inputs breaking news paragraph into DELPHI:
"Country A expels Country B diplomats following border skirmish in disputed valley."

Trace of execution across layers:
1. LAYER 1: Article ingested, tagged with timestamp 2026-10-26T12:00:00Z.
2. LAYER 2: Deterministic Custom Tokenizer splits text into 14 token IDs and
   a [14 x 16] character matrix.
3. LAYER 3: EventEmbed maps tokens into a sequence of [14 x 256] dense vectors.
   The Char-CNN recognizes "skirmish" morphology even if rare in vocabulary.
4. LAYER 4: EventNet BiLSTM + Self-Attention identifies:
   * Actor 1: "Country A" (IOB Tag: B-ACTOR)
   * Actor 2: "Country B" (IOB Tag: B-TARGET)
   * Event Code: CAMEO 0124 ("Expel diplomats")
5. LAYER 6: CredNet scores the publishing domain: Credibility = 0.88.
6. LAYER 5: Historical Matcher queries FAISS vector index:
   Retrieves 3 past analogues:
   - 2018 UK/Russia diplomat expulsion
   - 2020 India/China Galwan Valley standoff
   - 2021 Belarus/Poland border tensions
7. LAYER 7: CausalSeq projects 50 candidate trajectories for days t+1 to t+30.
8. LAYER 8: Forecast Orchestrator clusters trajectories:
   * Scenario 1 (Base Case, 54%): Reciprocal expulsion of diplomats within 7 days.
   * Scenario 2 (Escalation, 31%): Economic sanctions or trade restrictions.
   * Scenario 3 (De-escalation, 15%): Third-party diplomatic mediation.
9. LAYER 9: Leakage Guard confirms all checkpoints and data are <= 2026-10-26.
   Applies temperature scaling (T=1.3612) to finalize scenario probabilities.
10. LAYER 10: FastAPI serializes the forecast payload with execution time = 142ms.
11. LAYER 11: React UI renders the D3 causal forecast tree and tripwire indicators.
