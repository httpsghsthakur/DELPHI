# DELPHI — Predictive Intelligence Engine

DELPHI is a custom predictive intelligence research system that analyzes events and produces probability-weighted future scenarios.

## What DELPHI is
A custom predictive intelligence research system that analyzes events and produces probability-weighted future scenarios.

## What DELPHI is NOT
It is not:
- a chatbot
- an OpenAI wrapper
- a generic news summarizer
- a pretrained-model demo
- an oracle that knows the future
