# DELPHI — Predictive Intelligence Engine

DELPHI is a custom predictive intelligence research system that analyzes events and produces probability-weighted future scenarios.

## What DELPHI is
A custom predictive intelligence research system that analyzes events and produces probability-weighted future scenarios.

## What DELPHI is NOT
It is not:
- a chatbot
- an OpenAI wrapper
- a generic news summarizer
- a pretrained-model demo
- an oracle that knows the future

## Current status
Layer 1 (Data Foundation), Layer 2 (Custom Tokenizer), Layer 3 (EventEmbed), Layer 4 (EventNet), and Layer 5 (Historical Intelligence) are completed.
Data pipelines, custom embeddings, context-encoders, and FAISS-based evidence retrieval are implemented.
Next Layer: Layer 6 (CredNet)
Datasets not yet fully ingested (Real benchmark pending data preparation)
