# DELPHI — Predictive Intelligence Engine

DELPHI is a custom predictive intelligence research system that analyzes events and produces probability-weighted future scenarios.

## What DELPHI is
A custom predictive intelligence research system that analyzes events and produces probability-weighted future scenarios.

## What DELPHI is NOT
It is not:
- a chatbot
- an OpenAI wrapper
- a generic news summarizer
- a pretrained-model demo
- an oracle that knows the future

## Current status
Layer 1 (Data Foundation) and Layer 2 (Custom Tokenizer) are completed.
Data pipelines, canonical schemas, validation, deduplication, and leakage protection are implemented. The deterministic Custom Tokenizer is built from scratch for future models.
AI models not yet implemented
Datasets not yet ingested
